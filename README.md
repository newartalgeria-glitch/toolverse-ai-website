# 🚀 ToolVerse | تول فيرس
### منصة أدوات مجانية ذكية وسريعة (Client-Side & Zero-Cost)

منصة أدوات ويب عصرية وسريعة جداً، مصممة لتعمل **بالمجان 100% مدى الحياة (0$ تكلفة)** دون الحاجة إلى خوادم أو اشتراكات مدفوعة، وبدعم كامل للغتين **العربية** و**الإنجليزية** مع التبديل الفوري واتجاه النصوص (RTL / LTR).

---

## 🌟 مميزات المنصة:
1. **مجانية بالكامل (Zero-Cost):** جميع الأدوات تنفذ العمليات داخل متصفح الزائر مباشرة (Client-Side)، فلا توجد تكاليف خوادم أو استهلاك باندويث مدفوع.
2. **ثنائية اللغة بضغطة زر (Bilingual):** تحويل كامل للواجهة والخطوط واتجاه الصفحة بين العربية والانجليزية.
3. **أمان وخصوصية تامة:** لا يتم رفع صور الزائر أو نصوصه أو بياناته إلى أي خادم خارجي.
4. **تصميم احترافي وفائق السرعة:** واجهة داكنة زجاجية حديثة (Modern Glassmorphism) متوافقة مع جميع شاشات الهواتف والأجهزة اللوحية والحواسيب.
5. **بحث وفلترة فورية:** شريط بحث ذكي وتصنيفات سريعة للوصول للأداة في ثوانٍ.

---

## 🛠️ الأدوات المدمجة في الموقع:
* **أدوات ودمج ملفات PDF (PDF Tools & Merger):** دمج وجمع ملفات PDF متعددة في ملف واحد بسرعة فائقة وأمان تام 100% داخل المتصفح بدون أي سيرفرات.
* **مولد نصوص لوريم إيبسوم ونصوص عربية بديلة (Lorem Ipsum Generator):** توليد فقرات وجمل تجريبية للمصممين باللغتين العربية واللاتينية مع نسخ فوري.
* **الآلة الحاسبة التفاعلية (Interactive Pocket Calculator):** حاسبة رقمية سريعة للشاشات والحواسيب لجميع العمليات الحسابية والنسب.
* **محول حالة النصوص ومنظف التشكيل (Text Case Converter):** تحويل النصوص لحالات UPPERCASE, lowercase, camelCase, snake_case مع ميزة إزالة التشكيل من النصوص العربية.
* **محول القياسات والوحدات (Unit Converter):** تحويل فوري لوحدات الطول، الأوزان، ودرجات الحرارة.
* **مولد رموز QR الذكي (QR Code Generator):** توليد باركود لأي رابط أو نص مع تخصيص الألوان والحجم والتحميل بصيغة PNG.
* **ضاغط ومحول صيغ الصور (Image Compressor):** ضغط الصور بنسبة تصل إلى 80% مع تحويل الصيغ إلى WebP / JPG / PNG محلياً.
* **مولد كلمات المرور الآمنة (Password Generator):** توليد كلمات مرور معقدة ومشفرة عشوائياً مع شريط لقياس قوة الأمان.
* **محلل وعداد النصوص (Text Analyzer):** حساب الكلمات، الحروف، الأسطر، وتقدير وقت القراءة مع أدوات تنظيف النصوص.
* **منسق وفاحص JSON (JSON Formatter & Validator):** تدقيق بنية JSON واكتشاف الأخطاء وتنسيقها بمسافات بادئة أو تصغيرها (Minify).
* **حاسبة النسبة المئوية (Percentage Calculator):** حساب النسب، التغير بالنسبة المئوية، ومقدار الخصومات.
* **تشفير وفك تشفير Base64 (Base64 Codec):** معالجة نصوص UTF-8 والحروف العربية والرموز الخاصة بدقة.
* **منتقي ومحول الألوان (Color Picker):** تحويل فوري بين صيغ HEX و RGB و HSL مع معاينة التباين وسهولة النسخ.

## 💻 طريقة تشغيل الموقع الآن على جهازك:
لا تحتاج لتثبيت أي برامج أو حزم برمجية:
1. انتقل إلى المجلد: `C:\Users\PC 2025\.gemini\antigravity\scratch\toolverse\`
2. اضغط نقرتين (Double-Click) على ملف **`index.html`** لفتحه في أي متصفح (Edge، Chrome، Firefox).
3. سيعمل الموقع مباشرة بجميع أدواته!

## 🌐 كيف ترفع الموقع على الإنترنت مجاناً في 3 دقائق؟

### الطريقة الأولى: Cloudflare Pages (الموصى بها - مجانية وغير محدودة)
1. سجل حساباً مجانياً على [cloudflare.com](https://cloudflare.com).
2. اختر **Workers & Pages** ثم اضغط **Create application** -> **Pages**.
3. اختر **Direct Upload** (رفع مباشر) وقم بسحب وإفلات مجلد `toolverse` بالكامل.
4. ستحصل فوراً على رابط رسمي وسريع ومجاني مدى الحياة مثل: `https://toolverse.pages.dev` ومحمي بشهادة SSL.

### الطريقة الثانية: Vercel أو Netlify
1. ادخل إلى [vercel.com](https://vercel.com) أو [netlify.com](https://netlify.com).
2. اسحب مجلد `toolverse` إلى لوحة التحكم ليتم نشره في ثوانٍ برابط مجاني `.vercel.app`.
